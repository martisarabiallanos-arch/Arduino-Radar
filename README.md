# Arduino-Radar.

¡Hola! En este repositorio encontrarás un proyecto de radar utilizando una placa Arduino.
 En este proyecto el objetivo es construir un sistema capaz de detectar objetos a diferentes distancias y representar la información obtenida de forma visual mediante c#.

El proyecto va a combinar Arduino, un sensor ultrasónico y un servomotor para realizar un barrido de un área determinada. Mientras el servomotor mueve el sensor, este mide continuamente la distancia de los objetos que encuentra y Posteriormente, los datos se van a enviar mediante una computadora para visualizar el funcionamiento del radar en tiempo real .

 ¿Cómo va a funcionar?
El sistema va a realizar un movimiento de izquierda a derecha .
 Durante este proceso.

El servomotor se va a posicionar en diferentes ángulos y el sensor ultrasónico va a medir la distancia de los objetos.

Arduino va a procesar las mediciones que obtuvo y los datos van a enviarse mediante una comunicación serial.

La información se va a representar gráficamente mediante c# mostrando un radar.

Los Componentes que van a ser utilizados seran los siguientes:

Arduino

Sensor ultrasónico HC-SR04

Servomotor

Protoboard

Cables jumper

Computadora

Cable USB



Mis objetivos.
Este proyecto tiene su objetivo poner en práctica conceptos de programación, electrónica y comunicación serial, además de saber cómo  es el funcionamiento de los sensores de distancia, como construir la interfaz grafica para mostrar los datos, la construccion de piezas en 3d mediante impresora 3d  y  como se trabja con el servomotor mediante Arduino.

También puede servir como proyecto educativo para aprender sobre la integración de hardware y software en sistemas de detección.
